# AiSkills

Репозиторий содержит переносимые навыки для ИИ-агентов. Канонические исходники
навыков находятся в `src/skills`; они совместимы со стандартом Agent Skills и
могут подключаться к Codex и Claude Code без дублирования содержимого.

## Структура

- `src/skills` — каталог готовых навыков.
- `src/templates` — шаблоны и справочные материалы для авторов навыков.
- `tools` — локальные валидаторы структуры и переводов.
- `tools/scripts` — сценарии проверок, запускаемые в контейнере.
- `tools/docker` — Docker Compose-точки входа для проверок.
- `tests` — автоматические проверки и фикстуры.
- `docs` — подробная документация.

## Проверки

Для всех проверок требуется Docker Engine с Docker Compose. Контейнер содержит
Python 3.12 и зависимости разработки, поэтому запускать проверки напрямую из
Python на хосте не нужно.

На Windows, Linux и macOS используйте одни и те же команды:

```powershell
docker compose -f tools/docker/verify.yaml run --rm verify
docker compose -f tools/docker/tests.yaml run --rm tests
```

Первый запуск собирает локальный образ и кеш Docker; исходное дерево
монтируется в контейнеры только для чтения.

## Подключение навыка

Скопируйте папку нужного навыка из `src/skills/<skill-name>` в
`.agents/skills/` рабочего репозитория для Codex либо в `.claude/skills/` для
Claude Code. Подробнее — в [инструкции по подключению](docs/installation.md).

Русская документация является исходной. При её изменении обновляйте английскую
пару с суффиксом `_EN` в той же задаче.
