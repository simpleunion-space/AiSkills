# Подключение навыка

`src/skills` — единственный каталог-источник. Не добавляйте в этот репозиторий
симлинки и дублирующиеся представления для разных агентов.

Для Codex скопируйте папку нужного навыка в `.agents/skills/` целевого
репозитория. Для Claude Code скопируйте ту же папку в `.claude/skills/`.
Например, в PowerShell:

```powershell
Copy-Item -Recurse src/skills/example-skill <target>/.agents/skills/
```

Замените путь назначения на `<target>/.claude/skills/` для Claude Code. После
копирования перезапустите агент, если новая папка навыков не была обнаружена
текущей сессией автоматически.
