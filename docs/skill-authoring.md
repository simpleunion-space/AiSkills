# Создание навыка

Создайте каталог `src/skills/<skill-name>/`, где `<skill-name>` содержит только
строчные латинские буквы, цифры и одиночные дефисы. В нём обязателен английский
`SKILL.md` с YAML frontmatter и Markdown-инструкциями.

Обязательные поля frontmatter:

- `name` — в точности имя каталога;
- `description` — назначение навыка и ситуации, в которых его следует вызвать.
- `metadata.version` — строковая версия навыка в полном формате SemVer 2.0.

`metadata` — обязательное строковое отображение. Помимо `version` в нём можно
указывать необязательные строковые метаданные, например `author`. Стандартные
необязательные поля верхнего уровня: `license`, `compatibility` и
`allowed-tools`. Расширения конкретной платформы не добавляйте в общий
frontmatter. Для метаданных интерфейса Codex используйте `agents/openai.yaml`
внутри навыка.

## Версия навыка

Указывайте полную строку SemVer 2.0: `MAJOR.MINOR.PATCH`, при необходимости с
prerelease и build metadata, например `1.0.0-rc.1+build.42`. Префикс `v`,
пробелы и ведущие нули в числовых идентификаторах не допускаются. Начальная
версия нового навыка — `1.0.0`.

Версия обновляется вручную и независима от версии пакета `ai-skills` в
`pyproject.toml`. Увеличивайте MAJOR при несовместимом изменении контракта,
MINOR при новой совместимой возможности и PATCH при исправлении поведения.
Редактура без изменения поведения навыка не требует повышения версии.

Держите основной файл кратким. Развёрнутые справки размещайте в `references/`,
скрипты — в `scripts/`, статические шаблоны — в `assets/`. Все ссылки должны
быть относительными путями от корня навыка. Перед отправкой изменений выполните
валидатор навыков.
