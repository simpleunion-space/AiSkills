# Разработка

Все проверки выполняются Docker Compose на Windows, Linux и macOS. Контейнер
содержит Python 3.12, зависимости проекта и линтеры; не запускайте проверки
напрямую из Python на хосте.

| Действие | Команда | Побочные эффекты |
| --- | --- | --- |
| Verify | `docker compose -f tools/docker/verify.yaml run --rm verify` | Локальный образ и кеш Docker; исходники доступны только для чтения |
| Test | `docker compose -f tools/docker/tests.yaml run --rm tests` | Локальный образ и кеш Docker; выполняет verify, валидаторы, тесты и линтеры |

`verify` проверяет активный контракт репозитория и пробелы в Git diff. `tests`
сначала запускает `verify`, затем проверяет навыки и переводы, запускает pytest,
Ruff, ShellCheck и yamllint. Секреты не требуются. Если будущий навык будет
обращаться к внешнему сервису, документируйте его переменные окружения и
безопасный откат в самом навыке.
