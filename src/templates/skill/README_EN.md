# Skill template

Copy `SKILL.md.tmpl` to a new `src/skills/<skill-name>/SKILL.md` directory and
replace every value in angle brackets. Keep the required `metadata.version` and
change its value when appropriate. Remove only optional frontmatter fields that
do not apply: `license`, `compatibility`, `metadata.author`, and
`allowed-tools`. The directory name and `name` must match.

`SKILL.ru.md.tmpl` is a reference translation. Do not copy it as the runnable
`SKILL.md`. See the full [authoring documentation](../../../docs/skill-authoring_EN.md).
