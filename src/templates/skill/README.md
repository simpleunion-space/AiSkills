# Шаблон навыка

Скопируйте `SKILL.md.tmpl` в новый каталог `src/skills/<skill-name>/SKILL.md` и
замените все значения в угловых скобках. Сохраните обязательное
`metadata.version` и при необходимости измените его значение. Удалите только
необязательные поля frontmatter, которые не применимы: `license`,
`compatibility`, `metadata.author` и `allowed-tools`. Имя каталога и `name`
должны совпадать.

`SKILL.ru.md.tmpl` — справочный перевод. Его не копируют как исполняемый
`SKILL.md`. Полные правила приведены в
[документации для авторов](../../../docs/skill-authoring.md).
